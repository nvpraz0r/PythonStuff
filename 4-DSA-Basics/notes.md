# Big O Notation Notes

cheatsheet: https://www.bigocheatsheet.com

O(1) - constant
O(log n) - logarithmic
O(n) - linear
O(n ^ 2) - squared
O(2 ^ n) - exponential
O(n!) - factorial



O(1) == no matter the size of the input there is no growth in the runtime of the algorithm

O(n) == 1 for-loop
O(n ^ 2) == 2 for-loop
